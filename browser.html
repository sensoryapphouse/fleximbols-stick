Using Fleximbols Browser

This is a library of about 9,300 symbols you can browse, preview with display tweaks, and download as SVG.

Finding a symbol

  • Search — type in the box at the top-left to narrow by name (e.g. cat, school).
  • Turn the page — tap ◀ ▶ or, on a phone or tablet, swipe left/right across the grid. On a computer you can also use the keyboard's left/right/Home/End keys.
  • Jump to a page — type a number into the page box, or use ⏮ / ⏭ for first / last (on a phone in landscape these live inside the ☰ menu).
  • Gender — pick All, Male, Female, or Random. "Male" also shows symbols that have no gender. "Random" mixes male and female pairs.
  • Gender & content menu — the small All button opens a dropdown with two sections. Gender picks which figures to show (All, Male, Female, Random). Also show has two toggles that are off by default: Plurals & tenses reveals conjugated / plural variants (e.g. "will cut and paste"); Alphabets reveals the letter symbols. Both stay on across visits once ticked.
  • 18+ — tick to include sensitive / anatomy symbols. Off by default.
  • 📁 Categories — when ticked, symbols are shown in folder order (alphabetical by category, then alphabetical within each category). When unticked, every symbol is in one big A→Z list regardless of folder. Pagination works the same in both modes — just the order changes. A small badge appears in the top-left of the grid showing which category you're currently viewing.
  • Hamburger menu (☰) — on a phone, the gender, 18+ and category controls live inside the ☰ button to keep the toolbar tidy.

Preview transforms (🎨 Transform menu)

Try different looks without changing the original file. Pick any combination:

  • Border — original, none, thin, medium, or thick outlines.
  • Skin — change skin tone (light → dark) on figures that have skin.
  • Hair — change hair colour, or shuffle randomly.
  • Colour — bold (default) or muted palette.
  • Traditional — restyle figures to one of 60 traditional styles (clothing, accessories, complexion). Choose none to leave them as-is.
  • Clothes — recolour figure clothing (top and trousers).
  • CVI mode — high-contrast view for people with cortical visual impairment.
  • Reset all — clear every transform.

Transforms are preview-only — the SVG files on disk are never changed.

Downloading a symbol

  1. Tap a symbol — a preview popup appears.
  2. Tap ⬇ Download SVG.
  3. Any transforms you have set are baked into the downloaded file.
  4. Close the popup with the × button, by tapping outside it, or by tapping the symbol again.

Leaving feedback on a symbol

Inside the preview popup there's a 💬 Leave feedback section. Tap it to expand a small text box.

  • Type up to 500 characters about what's good or what could be better.
  • Tap Send. A "Thanks!" message confirms it was received.
  • Your feedback is sent with the symbol's name and any transforms you had active (e.g. skin tone, culture) so the team can see exactly what you were looking at.
  • Feedback is anonymous from your side — no sign-in needed. Please be kind.

Layout on different devices

The browser adapts to whatever screen you're on:

  • Computer — wide grid with the toolbar across the top.
  • Tablet — slightly smaller grid, same toolbar.
  • Phone — portrait — fewer columns per page, tools collapse into a ☰ menu so the search box stays visible.
  • Phone — landscape — toolbar moves to a thin rail on the left so the symbols get the full height of the screen.

Tips

  • SVG files scale to any size without losing sharpness — useful for printing or large displays.
  • Swipe left or right on a phone or tablet to flip pages, just like a photo gallery.
  • If a transform looks odd on a particular symbol, try Reset all and apply changes one at a time.
  • This is an alpha — please be patient with any rough edges.
